## minSdk 제안

**MVP 최소 지원 버전: API 26 (Android 8.0)**

### 이유

* `MediaProjection`은 **API 21부터 사용 가능**
* 플로팅 버튼에 사용할 `TYPE_APPLICATION_OVERLAY`는 **API 26부터 지원**
* **Android 7.0~7.1 = API 24~25**
* API 24~25까지 지원하려면 **구형 Overlay 방식 별도 구현 + 버전 분기 + 추가 테스트** 필요
* 2026년 8월 국내 Android 사용 통계 기준, **Android 12~16 + Android 10이 약 96.99%**
* 따라서 **Android 11·9·8·7 등을 모두 합친 구형 버전 비중도 약 3.01%**이며, Android 7.x는 그보다 더 작은 일부
* MVP 단계에서는 구형 단말 호환보다 **핵심 기능 검증을 우선**

### 제안

> 우선 `minSdk = 26`으로 MVP를 개발한다.
> 이후 실제 사용자 조사에서 **Android 7.x(API 24~25)** 사용 수요가 유의미하게 확인되면, 구형 Overlay 호환 로직을 추가한다.

즉, **초기에는 API 26 이상으로 단순하게 개발하고, 실제 수요가 확인될 때만 구형 버전을 대응하는 방향**.
